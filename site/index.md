# Keyboard and focus evidence for Playwright

**a11y-journey-evidence · experimental v0.1.0**

Keep native Playwright actions and assertions. Add an opt-in journey fixture and reporter to collect ordered keyboard/focus observations and portable Markdown evidence.

[Get started](./getting-started.md) with a synthetic dialog and form. The package records evidence for the assertions you execute; external validation is pending.

- [Install from npm](https://www.npmjs.com/package/a11y-journey-evidence/v/0.1.0)
- [Released source](https://github.com/Light2288/a11y-journey-evidence/tree/v0.1.0)
- [GitHub release](https://github.com/Light2288/a11y-journey-evidence/releases/tag/v0.1.0)

The tested package baseline is Chromium, one main document and ordinary light DOM. Evidence can contain application data. It does not establish accessibility conformance or screen-reader behavior.
