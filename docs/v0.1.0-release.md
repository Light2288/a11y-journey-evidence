```sh
npm publish .artifacts/release/a11y-journey-evidence-0.1.0.tgz --access public --tag latest --registry=https://registry.npmjs.org
```

It exited **1 / E403**, with the registry diagnostic: `Two-factor authentication or granular access token with bypass 2fa enabled is required to publish packages.` Local sign-in alone did not satisfy publishing authentication. A subsequent `npm view a11y-journey-evidence@0.1.0 version dist.integrity --json --registry=https://registry.npmjs.org` exited **1 / E404**. No publication was confirmed and no blind retry was made.
