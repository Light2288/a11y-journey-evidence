## Review Focus

1. Invalid/conflicting source arguments or a missing explicit tarball must fail contextually without falling back to packing the checkout. Task 2 adds subprocess regressions.
2. A cached or checkout installation must not masquerade as the candidate or registry package. Tasks 2, 3, and 5 check installation location, exact version, dependency source, and integrity in a fresh external consumer.
3. An archive modified after verification must not be uploaded under the earlier evidence. Tasks 3 and 4 compare the archive's SHA-512 integrity at freezing, review, and publication boundaries.
4. ENEEDAUTH, unexpected ownership, or a taken name/version must leave publication pending with the exact reason. Task 4 checks read-only npm identity and registry preconditions before any registry write.
5. An ambiguous upload result or delayed registry visibility must not trigger blind republication or a false completion claim. Tasks 4 and 5 inspect actual registry metadata and distinguish publication from consumer-verification status.
