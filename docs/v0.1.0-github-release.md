## Release notes

Experimental keyboard and focus evidence for native Playwright Test journeys.

### Install from npm

Use Node **24.21.0** and the tested Playwright Test peer:

```sh
npm install --save-dev a11y-journey-evidence@0.1.0 @playwright/test@1.64.1
npx playwright install chromium
```

[npm package: a11y-journey-evidence@0.1.0](https://www.npmjs.com/package/a11y-journey-evidence/v/0.1.0)

### Included in v0.1.0

- An opt-in test fixture and reporter that preserve native `page.keyboard`, locators, `test.step`, and `expect`. Compose existing fixtures using Playwright's `mergeTests`, then call `journey.start({ root })` after page setup.
- [Dialog journeys](https://github.com/Light2288/a11y-journey-evidence/blob/v0.1.0/examples/shared/dialog-journey.ts) for initial focus, both containment boundaries, Escape dismissal, and focus restoration.
- [Form journeys](https://github.com/Light2288/a11y-journey-evidence/blob/v0.1.0/examples/shared/form-journey.ts) for keyboard submission, declared error associations, invalid-submit focus, correction, and successful resubmission.
- Portable Markdown evidence that retains native actual/expected outcomes, executed assertions, keyboard/focus observations, and completeness disclosures. Available failure artifacts include screenshots, scoped ARIA snapshots, and existing native traces.
- An [equivalent stock Playwright comparison](https://github.com/Light2288/a11y-journey-evidence/tree/v0.1.0/examples/stock) and [author comparison findings](https://github.com/Light2288/a11y-journey-evidence/blob/v0.1.0/docs/batch-2-comparison.md).

See the [v0.1.0 guide](https://github.com/Light2288/a11y-journey-evidence/blob/v0.1.0/README.md) for fixture composition, reporter setup, capture controls, reproduction commands, and the complete limitations.

### Tested compatibility and limits

Verified locally with Node **24.21.0**, npm **11.19.0**, TypeScript **7.0.2**, Playwright **1.64.1**, Chromium **156.0.8078.4**, and macOS **27.0.1 arm64**. Other hosts, runtimes, browsers, and CI remain untested.

Supported recording is limited to Chromium, one page/main document, ordinary light DOM, and the explicit journey under test. Frames, new pages, shadow traversal, navigation/document replacement, and additional patterns are outside this release's supported scope. Captures describe fixture-teardown state when available; incomplete observations and unavailable captures are disclosed separately from native test outcomes.

Screenshots, ARIA snapshots, attributes, diagnostics, and traces can contain application data. Printable-input filtering is not general sanitization; use synthetic data and inspect bundles before sharing.

**External validation is pending.** Author comparisons do not establish independent usefulness or measured time savings. This package does not establish accessibility conformance, screen-reader announcements, or inclusive usability.

Install the compiled distribution from npm. GitHub's automatic source archives are repository snapshots; they do not contain the compiled npm distribution.
